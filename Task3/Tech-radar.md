### Технический радар

Статус технологий и методологий в компании: 
* ADOPT - что используем 
* TRIAL - что пробуем 
* ASSESS - что оцениваем
* HOLD - от чего отказываемся

| Категория | Статус | Технологии и методологии | Комментарий |
| :--- | :--- | :--- | :--- |
| **Методологии и подходы** | **ADOPT** | Domain-Driven Design (DDD), Data as a Product, CI/CD для данных, Agile/Scrum | Основа для новой архитектуры. Позволит определить границы доменов и создавать ценные, качественные «продукты данных». |
| | **TRIAL** | Self-Service аналитика, Data Governance Framework | Начинаем внедрять на пилотных проектах. Это ядро для «витрины данных». |
| | **ASSESS** | FinOps | С переходом в облако потребуется управление затратами на инфраструктуру. |
| | **HOLD** | Монолитная архитектура DWH, Waterfall-разработка для данных | Причина текущих проблем. Не масштабируется и замедляет развитие. |
| **Платформы** | **ADOPT** | Облачная платформа (Yandex Cloud, VK Cloud, MWS), Kubernetes | Перенос инфраструктуры в облако даст масштабируемость, гибкость и доступ к современным сервисам. |
| | **TRIAL** | Облачное DWH/Lakehouse, Платформа стриминга событий (Apache Kafka, Yandex Data Streams) | Основа для новой аналитической платформы. Kafka заменит старую шину данных для асинхронного обмена между доменами. |
| | **ASSESS** | Каталог данных, Платформы MLOps (MLflow, Kubeflow) | Каталог — ключевой компонент для «витрины данных». MLOps-платформы — для стандартизации работы ИИ-сервисов. |
| | **HOLD** | MS SQL Server 2008, Apache Camel (в текущей реализации) | Устаревшая СУБД — главный источник проблем. Camel можно заменить более современным и масштабируемым решением на базе Kafka. |
| **Инструменты** | **ADOPT**| Power BI, dbt (Data Build Tool), Git, Docker | Power BI остается как BI-инструмент. dbt станет стандартом для трансформаций данных в новой архитектуре (SQL + Jinja). |
| | **TRIAL** | Оркестратор (Airflow), Инструменты качества данных (Great Expectations) | Для построения надежных и наблюдаемых data-пайплайнов. |
| | **ASSESS** | Инструменты для стриминговой обработки (Apache Flink, Spark Streaming) | Понадобятся для аналитики в реальном времени. |
| | **HOLD**| Power Builder | Устаревший инструмент для создания интерфейсов. Будет заменен современным веб-фреймворком для портала. |
| **Языки и фреймворки** | **ADOPT** | Python, Go, Java, SQL | Текущие языки полностью соответствуют задачам. SQL остается главным языком для аналитиков. |
| | **TRIAL** | React / Vue.js (для портала самообслуживания) | Для создания современного, интерактивного интерфейса «витрины данных». |
